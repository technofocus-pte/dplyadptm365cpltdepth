# Laboratorio 3: Capacitación personalizada con Learning agent en Microsoft 365 Copilot

![](./media/image1.png)

## Introducción

Learning agent permite a las personas crecer continuamente y lograr más
mediante el aprendizaje personalizado, en el momento adecuado,
directamente dentro de Microsoft 365 Copilot. Ayuda a los usuarios a
desarrollar habilidades técnicas y blandas, mejorar competencias y
aprender a utilizar Copilot de manera más efectiva en el trabajo diario.

Learning agent utiliza IA para proporcionar:

- Recomendaciones de aprendizaje personalizadas

- Rutas de aprendizaje seleccionadas

- Práctica interactiva mediante simulación de roles

- Contenido de aprendizaje empresarial y de terceros (incluido LinkedIn
  Learning)

------------------------------------------------------------------------

## Objetivos del laboratorio

Al finalizar esta guía, podrá:

  Acceder e iniciar Learning agent  
  • Descubrir recomendaciones de aprendizaje personalizadas  
  • Practicar habilidades mediante simulación de roles  
  • Utilizar prompts de Learning agent para capacitación continua

**Nota:** Las recomendaciones de Learning agent se personalizan según el
rol, las habilidades y la actividad del usuario. En entornos de vista
previa, los resultados pueden variar según los datos de perfil y del
tenant disponibles.

------------------------------------------------------------------------

## Requisitos previos

- Licencia de Microsoft 365 Copilot

- Acceso a Learning agent (Frontier – Private Preview)

- Usuario habilitado para Frontier por el administrador

- Opcional: Viva Learning / Viva Suite (mejora la experiencia de
  aprendizaje, pero no es obligatorio)

## Plataformas compatibles

- Microsoft 365 Copilot Web

- Microsoft 365 Copilot Chat (Native App)

- Microsoft Teams (Web & App – Preview)

### No compatible (vista previa actual):

- Word Copilot

- Excel Copilot

- PowerPoint Copilot

## Ejecución paso a paso

## Paso 1: Acceder a Learning agent

1.  Abra **Microsoft 365 Copilot** (Web o Teams).

  - Inicie sesión con sus credenciales de ODL.

    ![](./media/image2.png)

  - Haga clic en Yes para continuar.

    ![](./media/image3.png)

  - Una vez que haya iniciado sesión correctamente, aparecerá la pantalla
    de bienvenida de Copilot Chat.

    ![](./media/image4.png)

2.  En el panel de navegación izquierdo de M365 Copilot, vaya a **New
    chat** y seleccione **All agents**.

    ![](./media/image5.png)

3.  Explore Agent store

    ![](./media/image6.png)

4.  Busque **Learning** en **Agent store** y seleccione **Learning
    (Frontier)**.

    ![](./media/image7.png)

5.  Haga clic en el botón **Add** para habilitar el agente.

    ![](./media/image8.png)

6.  Visualice **Learning (Frontier)** habilitado en la sección
    **Agents** en el panel de navegación izquierdo de M365 Copilot.

    ![](./media/image9.png)

### Resultado esperado

- Learning agent se abre y está listo para usarse.

## Paso 7: Hacer seguimiento del aprendizaje y crear hábitos

1.  Revise recordatorios o notificaciones de aprendizaje.

2.  Observe elementos de gamificación como:

    - Rachas de aprendizaje

    - Indicadores de progreso

**Nota: En una máquina virtual o en un tenant nuevo, los indicadores
completos de progreso y las rachas de aprendizaje pueden NO mostrarse
visiblemente durante una demostración corta**.

### Beneficio:

Fomenta el aprendizaje continuo sin interrumpir el trabajo diario.

## Conclusiones clave

- Learning agent integra el aprendizaje directamente en el flujo de
  trabajo.
- Las recomendaciones son personalizadas y adaptativas.  
- La simulación de roles permite practicar habilidades de forma segura.  
- La capacitación en Copilot se integra en las tareas diarias.  
- El contenido empresarial y de terceros se unifica en un solo lugar.
